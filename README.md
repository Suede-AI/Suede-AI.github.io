# Suede-AI.github.io

Landing page for **Stake Your Claim** — a book by Jason "Johnny Suede" Colapietro on
turning the AI onslaught into a real asset, autonomous agents, and building
generational wealth as a creative.

**Live:** [https://suede-ai.github.io](https://suede-ai.github.io)

## What's here

- `index.html` — book landing page with summary, part overview, and call-to-action
- `book.html` — the full book, single-file long-form HTML
- `notes/` — field notes applying the book to AI search, public proof, Google Business Profiles and directories, customer proof as structured evidence, and SEO/GEO work (West Palm Beach and Jupiter), with shared `notes/notes.css`
- `llms.txt` / `llms-full.txt` — plain-text site map and full note text for AI crawlers
- `scripts/check-notes.mjs` — guard for notes metadata, canonical JSON-LD @ids, sitemap/llms coverage and forbidden terms
- `robots.txt` — explicit allowlist for major search and AI crawlers
- `sitemap.xml` — sitemap listing `/`, `/book.html` and the notes
- `LICENSE` — MIT

## Deploy

This repo is deployed via **GitHub Pages from `main`**. Any push to `main`
triggers a `pages build and deployment` workflow that publishes the static
site to `https://suede-ai.github.io`. There is no build step — the HTML files
are served directly.
